NEON VOID is a neon arena-survival roguelite: survive 10 escalating waves of enemies, chain kills into combos, and pick 1 of 3 upgrades between waves. Keyboard and mouse, synthesized WebAudio sound effects, no build step.

## Run it

```sh
python3 -m http.server --directory game 8000
```

Then open http://localhost:8000 in a desktop browser.
